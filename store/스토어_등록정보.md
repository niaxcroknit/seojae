# 스토어 등록정보 (복사해서 붙여넣기)

Play Console → **성장 → 스토어 등록정보 → 기본 스토어 등록정보**에 그대로 붙여넣으면 돼요.

---

## 앱 이름 (30자 이내)

```
서재한켠 - 독서 기록과 형광펜
```

## 간단한 설명 (80자 이내)

```
가진 책, 읽은 책, 마음에 남은 문장까지. 한줄평과 형광펜으로 가볍게 남기는 독서 노트
```

## 자세한 설명 (4,000자 이내)

```
서재한켠은 내가 가진 책을 서재처럼 꽂아 두고, 읽은 기록을 가볍게 남기는 독서 노트예요.
회원가입 없이 바로 쓰고, 모든 기록은 내 폰에만 저장돼요.

■ 내 서재
· 표지를 찍거나 앨범에서 골라 책을 꽂아요. 비스듬히 찍어도 반듯하게 펴서 표지로 써요.
· 안 읽음 / 읽는 중 / 다 읽음으로 나눠 보고, 제목이나 저자로 찾아요.

■ 읽는 중
· 서재 목록에서 바로 지금 읽은 쪽수를 고쳐요. 진도 막대가 함께 채워져요.
· 읽다가 남기고 싶은 쪽에서 페이지 메모를 남겨요.

■ 다 읽은 뒤
· '다 읽음'을 누르면 한줄평을 남길 수 있게 바로 안내해요.
· 별점과 한줄평, 그리고 길게 쓰고 싶은 날엔 감상을 통으로 써요.

■ 형광펜
· 감상이나 페이지 메모에서 문장을 골라 형광펜을 칠해요.
· 칠한 문장은 형광펜 모음에 어디서 칠했는지(감상, p.123)와 함께 모여요.

■ 올해 기록
· 올해 완독한 책, 읽은 쪽수, 칠한 형광펜 수와 월별 완독을 한눈에 봐요.

■ 내 기록은 내 폰에
· 로그인도, 서버도 없어요. 기록은 이 폰 안에만 저장돼요.
· '기록 내보내기'로 파일을 만들어 드라이브나 메일에 보관할 수 있어요.
```
