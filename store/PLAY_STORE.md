메뉴 이름은 Play Console 화면이 바뀌면 조금 다를 수 있어요. 그럴 땐 비슷한 이름을 찾거나 캡처해서 보여 주세요.

|---|---|

| 앱 또는 게임 | 앱 |

### 데이터 보안 답변

이 앱은 기록을 폰 안에만 저장하고 어디에도 보내지 않아서 아주 간단해요.

| 질문 | 답 |
|---|---|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **아니요** |
| (다음 화면) | 저장 → 제출 |

> 표지 사진과 기록은 폰 안에서만 쓰이고, '기록 내보내기'는 사용자가 직접 보낼 곳을 고르는 기능이라 '수집'에 해당하지 않아요.

왼쪽 메뉴 **성장 → 스토어 등록정보 → 스토어 설정**(또는 '앱 카테고리 선택 및 연락처 세부정보 제공')

- 앱 카테고리: **도서 및 참고자료**
- 연락처 이메일: 내 이메일

## 5. 기본 스토어 등록정보

왼쪽 메뉴 **성장 → 스토어 등록정보 → 기본 스토어 등록정보**

- 앱 이름, 간단한 설명, 자세한 설명: `스토어_등록정보.md`에서 복사
- 앱 아이콘: `app-icon-512.png`
- 그래픽 이미지: `feature-graphic-1024x500.png`
- 휴대전화 스크린샷: `screenshot-1.png` ~ `screenshot-5.png` 순서대로

→ **저장**

## 6. 비공개 테스트 시작

개인 개발자 계정은 **비공개 테스트에 테스터 12명 이상이 14일 동안 계속 참여**해야 정식 출시(프로덕션)를 신청할 수 있어요. 단단 때와 같아요.

1. 왼쪽 메뉴 **테스트 및 출시 → 테스트 → 비공개 테스트** → **트랙 만들기**(또는 기본 'Closed testing - Alpha' 사용)
2. **테스터** 탭 → **이메일 목록 만들기** → 이름 `서재한켠 테스터` → 테스터 12명 이상의 이메일 입력 → 저장
   (단단 때 만든 목록이 있으면 그걸 체크해도 돼요)
3. **피드백 URL 또는 이메일**에 내 이메일
4. **새 버전 만들기**
   - 처음이면 **Play 앱 서명** 안내가 나와요 → 기본값(Google에서 관리) 그대로 **계속**
   - **App Bundle 업로드**에 `app-release.aab`를 끌어다 놓기
   - 출시 이름: `1.0.0` (자동으로 채워지면 그대로)
   - 출시 노트:
     ```
     <ko-KR>
     서재한켠 첫 버전이에요. 표지 사진으로 책을 꽂고, 한줄평·감상·페이지 메모·형광펜으로 기록해 보세요.
     </ko-KR>
     ```
5. **다음 → 저장 → 출시 검토 → 비공개 테스트 트랙으로 출시 시작**
6. 검토가 끝나면(보통 며칠) **테스터** 탭의 **웹에서 참여** 링크를 테스터들에게 보내요.
   테스터는 링크에서 **테스터 되기**를 누른 뒤 Play 스토어에서 설치해요.

> 14일은 테스터 12명이 **참여(옵트인)한 날부터** 세요. 중간에 테스트를 그만두는 사람이 없게 부탁해 두세요.

## 7. 프로덕션(정식 출시) 신청

14일이 지나면 대시보드에 **프로덕션 액세스 신청** 버튼이 열려요.

1. 테스트를 어떻게 했는지 묻는 질문에 답해요. 예시:
   - 테스터 모집: 지인과 독서 모임 사람들에게 링크를 보내 모집했어요.
   - 받은 피드백: 쪽수를 목록에서 바로 고치고 싶다는 의견, 다 읽은 뒤 한줄평 안내가 좋다는 의견 등
   - 반영한 것: 실제로 고친 것을 적어요
2. 승인되면 **테스트 및 출시 → 프로덕션 → 새 버전 만들기** → 비공개 테스트 버전을 **라이브러리에서 추가** → 출시
